    Download for

    The offline copy needs Node.js 18 or newer. The first AI use downloads the model once; after that the console works without the internet. The browser copy needs nothing installed and can be added to the home screen.

    AI answers can be wrong. The written action cards stay available on every copy. ExMonitor is a training simulation, not a medical device.

    Open it in a minute.

    Phones need no install. The computer copy is one file to start and then works offline.

    1. On a phone

      Open exmonitor.extem.net/app and add it to the home screen. The sensor page is part of the same address.

    2. On a computer: unzip the folder

      Put it somewhere you can find again. Nothing installs into the system.

    3. Start the single launcher

      The ZIP you download contains one start file for your system. Double-click it, or run it in a terminal on Linux.

    4. Open the sensor page

      The launcher prints an address for your network. Open that address with /sensors.html on a phone, then scan its code in Settings.
