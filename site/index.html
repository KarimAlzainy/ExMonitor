    Download ZIP

    A folder with the console, the sensor page and the launcher.

    Unzip it, then run Start Ex-Monitor. Node.js 18 or newer is required. The first AI use downloads the model once; after that the console works without the internet.

    AI answers can be wrong. The written NASA action cards stay available on every copy. Ex-Monitor is a training simulation, not a medical device.

    From ZIP to console in a minute.

    1. Unzip the folder

      Put it somewhere you can find again. Nothing installs into the system.

    2. Start the launcher

      Windows: double-click Start Ex-Monitor.cmd. macOS: double-click Start Ex-Monitor.command. Linux: run ./start-ex-monitor.sh.

    3. Open the sensor page

      The launcher prints an address for your network. Open that address with /sensors.html on a phone, then scan its code in Settings.
