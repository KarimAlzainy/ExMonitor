# Credits and licences

ExMonitor is a training simulation built for the 2026 NASA Space Apps Challenge. This file lists every
third-party dependency, AI model, font, icon set, asset and data source it uses. Nothing here is affiliated with
or endorsed by NASA.

## How this was built

Most of the code and copy were produced in a pair-programming loop between the human author and an AI coding
agent running in OpenCode. The author chose the direction, reviewed every change, and ran the build and the app.
The assistant that answers at runtime is also AI output and can be wrong. No images, audio or video in this
repository were generated by an image, audio or video model.

## AI models

The on-device assistant can use one of three models. The weights are downloaded once by WebLLM, cached by the
browser, and then run locally. The app never sends a prompt to a server for these models.

| Model in the app | Weights | Licence | Model card |
| --- | --- | --- | --- |
| Phi-3.5 mini | `Phi-3.5-mini-instruct-q4f16_1-MLC` | MIT | <https://huggingface.co/microsoft/Phi-3.5-mini-instruct> |
| Llama 3.2 3B | `Llama-3.2-3B-Instruct-q4f16_1-MLC` | Llama 3.2 Community License | <https://huggingface.co/meta-llama/Llama-3.2-3B-Instruct> |
| Gemma 2 2B | `gemma-2-2b-it-q4f16_1-MLC` | Gemma Terms of Use | <https://huggingface.co/google/gemma-2-2b-it> |

The quantised `-q4f16_1-MLC` builds are the WebLLM conversions published by the MLC AI project on Hugging Face
(<https://huggingface.co/mlc-ai>). Check each model card before redistributing a model or its weights; the Llama
and Gemma licences are not open-source licences in the same sense as MIT.

## Local model server

The assistant can also talk to a model you already run yourself, through [Ollama](https://ollama.com)
(MIT licence). ExMonitor does not bundle Ollama or any Ollama model; it only sends requests to the address you
enter. Model licences for that path come from whatever you pulled with Ollama.

## NASA data

One figure in the app comes from a published NASA document:

- **NASA-STD-3001 Volume 1, Revision C** — a 600 mSv career effective-dose limit and a 250 mSv limit per solar
  particle event. The Radiation card and `src/services/safetyRules.ts` use the 600 mSv career limit. The
  requirements are published at <https://www.nasa.gov/reference/4-0-human-performance> (sections 4.8 and
  [V1 4030]/[V1 4031]).

No other NASA document number is cited. Earlier drafts quoted `MR092L`, `MEDB 5.2`, `EVA-3.8`, `MED-10.4`,
`MED-8.1`, `Med-3.2`, `EVA Med-Rule 4.1.2`, `EMU Suit Ops 2.4` and a "25 mSv 30-day" limit. Those could not be
verified against any published NASA document and were removed in commit `e4a6126`.

The NASA Space Apps Challenge name and the challenge itself belong to NASA. This project uses no NASA logo,
meatball, flag, mission patch or other NASA branding.

## Assets

All image assets are the project's own icon set. The SVG files contain only a few path commands (a pulse line),
and the PNGs are rasterisations of the same mark at 32, 180, 192 and 512 pixels:

- `public/favicon.svg`, `public/masked-icon.svg`
- `public/favicon-32x32.png`, `public/apple-touch-icon.png`, `public/pwa-192x192.png`, `public/pwa-512x512.png`
- `site/favicon.svg`
- `docs/*.png` — screenshots of the running app, taken by the author

No stock photographs, icon packs, sound files, music or video are included. The alert sounds are generated at
runtime with the Web Audio API (`src/services/audioSynth.ts`); no audio file is shipped.
